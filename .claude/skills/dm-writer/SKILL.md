# DM Writer

## Rules

- Never open with a pitch. Reference something specific and genuine (their post, their comment, a shared context) in the first line.
- Keep it short — 2-4 sentences. A DM is a conversation opener, not a sales page.
- End with a low-friction question, not a hard ask ("Would it be useful if I sent over X?" beats "Book a call with me").
- Personalize using whatever real detail is available (their recent post, their company, the comment they left) — a template-obviously DM gets ignored.

## Output

Provide 2-3 variants at different levels of directness (soft nurture / direct-but-friendly / clearly commercial) so the user can pick based on relationship warmth.
