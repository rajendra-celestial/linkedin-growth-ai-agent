# Newsletter Writer

Maps to the Newsletter Idea content type — see [_shared/content-types.md](../_shared/content-types.md), stored under `/content/ideas`.

## Steps

1. Pick one focused theme per edition — newsletters that try to cover everything get skimmed and unsubscribed from.
2. Structure: a hook, one core idea explored in depth (with examples), a short actionable takeaway, and a CTA to reply/comment/subscribe.
3. If writing a teaser post (not the full edition), the goal is curiosity, not summary: give away the "what" but not the "how".
4. Keep a consistent edition-to-edition format (e.g. always 3 sections) — familiarity increases open rates over time.
