# Content Strategy

Combine the profile analysis (niche, ICP, positioning — see `profile-analysis` skill, read from `content/profile/profile-analysis.md` if it exists) with the content type catalog in [_shared/content-types.md](../_shared/content-types.md) to produce a pillar-based strategy.

## Steps

1. Identify 3-5 content pillars tied directly to the ICP's pain points and the author's proof of expertise — not generic categories like "tips" and "news".
2. Map each pillar to a rotation of content types from the catalog (e.g. a "Founder lessons" pillar → Lesson Learned, Mistake, Behind the Scenes).
3. Recommend a weekly cadence (how many posts/week, which days) and how it should evolve as engagement feedback comes in (what the user reports as performing well).
4. Hand off to `content-calendar` skill to turn the strategy into dated entries, and to `content-writing` to generate individual pieces.
