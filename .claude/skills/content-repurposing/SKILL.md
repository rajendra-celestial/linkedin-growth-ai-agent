# Content Repurposing

## Steps

1. Extract the 3-5 strongest standalone ideas from the source material — each should be able to stand alone as a post.
2. Map each idea to the format that suits it best:
   - A step-by-step idea → `CAROUSEL` or `HOW_TO`
   - A narrative/insight → `LONG_POST` or `STORY_POST`
   - A single strong quote/stat → `SHORT_POST` or `CAROUSEL_SLIDE`
   - A talking point → `VIDEO_SCRIPT` or `REEL_SCRIPT`
   - Episode takeaways → `PODCAST_NOTES`
3. Don't just summarize — rewrite each idea in the author's LinkedIn voice with its own hook and CTA; repurposed content that reads like a transcript underperforms.
4. Generate each via `content-writing` with the source idea passed as `topic`/`extraInstructions`.
