# Hook Generation

Reference set: [content/hooks/hook-library.md](../../../content/hooks/hook-library.md), grouped by category (curiosity, contrarian, story, authority, data, mistake, pattern-interrupt, question, confession, framework).

## Steps

1. Pick 1-2 categories that fit the post's intent (e.g. a case study post pairs well with authority or data).
2. Write hooks that are specific to the user's topic/niche — never reuse the library's placeholder text verbatim in production content; use it only as a style reference.
3. A good hook is under 15 words, creates an open loop, and contains no hashtags or emoji.
4. If the user reports a hook performed well, add it to the matching category section in `content/hooks/hook-library.md` so future sessions can draw on it.
