# Hashtag Generator

## Rules

- 3-5 hashtags maximum. LinkedIn's algorithm penalizes hashtag stuffing.
- Mix one broad tag (e.g. #Leadership), one niche/industry tag (e.g. #SaaSGrowth), and one specific/branded or trending tag.
- Hashtags should reflect the `keywords` already chosen for the post (see `linkedin-seo` skill) — don't introduce unrelated tags just for reach.
- List them as plain words without the `#` symbol in the post's frontmatter `hashtags` field; add the `#` only in the rendered post body.
