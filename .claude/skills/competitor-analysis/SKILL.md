# Competitor Analysis

## Steps

1. List 3-5 direct competitors or peers the user names (or infers from niche/ICP).
2. For each, note: their stated positioning, their 2-3 recurring content themes, and what seems to work for them (based on what's visible — post frequency, format mix, apparent engagement).
3. Identify white space: an angle, format, or audience segment competitors are neglecting.
4. Store structured findings in `Profile.competitorsJson` and turn the sharpest gap into a `CONTRARIAN_OPINION` or `PROBLEM_SOLUTION` post idea via `content-writing`.

Never scrape or access an actual competitor's private account data — work only from what the user provides or from public information.
