# Content Type Catalog

Shared reference used by multiple skills (`content-strategy`, `content-writing`, `content-calendar`, `content-repurposing`). Each type maps to a subfolder under `/content` where finished pieces should be written as markdown files.

| Content type | Guidance | `/content` folder |
|---|---|---|
| Daily Post | A general high-value daily post relevant to the niche. | `daily` |
| Story Post | Personal, narrative-driven: beginning, conflict, resolution. | `daily` |
| Educational Post | Teaches one clear, actionable insight. | `daily` |
| Carousel | 6-10 slide outline, one idea per slide, strong cover + CTA slide. | `carousel` |
| Poll | Sharp question + 2-4 short options, with context copy above it. | `polls` |
| Comment Idea | 5 thoughtful, non-generic comments for other people's posts. | `comments` |
| Short Post | Under 80 words, no fluff. | `daily` |
| Long Post | 250-400 words, deep insight, strong narrative arc. | `daily` |
| Founder Post | Founder-voice update or unfiltered opinion. | `daily` |
| Sales Post | Soft-sell, creates demand without being pushy. | `daily` |
| Case Study | Problem → approach → result, with real (illustrative) numbers. | `ideas` |
| Success Story | A win, framed to be relatable and inspiring. | `ideas` |
| Lesson Learned | Vulnerable, specific lesson from a failure or hard moment. | `ideas` |
| Behind the Scenes | How the work actually gets done; humanizes the brand. | `daily` |
| Product Update | What shipped and why it matters to the reader. | `daily` |
| Launch Post | Builds excitement/urgency for something new. | `daily` |
| Hiring Post | Sells the role and culture, not just the job spec. | `daily` |
| AI News | Original commentary reacting to recent AI news. | `daily` |
| Industry News | Original commentary reacting to industry news. | `daily` |
| Personal Branding | Reinforces personal brand positioning and authority. | `daily` |
| Thought Leadership | Bold, opinionated, stakes out a clear position. | `daily` |
| Conversation Post | Designed purely to start a conversation in comments. | `daily` |
| Contrarian Opinion | Challenges common wisdom, backed by reasoning. | `daily` |
| FAQ | Answers a frequently asked question in depth. | `ideas` |
| Mistake | A common mistake in the niche and how to avoid it. | `ideas` |
| Tip | One highly specific, immediately actionable tip. | `ideas` |
| Framework | A named, memorable, reusable framework. | `ideas` |
| How-To | Genuinely useful step-by-step, no gatekeeping. | `daily` |
| Customer Story | Told from the customer's perspective. | `ideas` |
| Problem-Solution | Names a specific painful problem, then the solution. | `daily` |
| Myth Busting | Names a common myth and debunks it with evidence/logic. | `daily` |
| Trending Topic | Connects a current trend back to the niche with a unique angle. | `daily` |
| Weekly Recap | Summarizes lessons/wins/content from the past week. | `weekly` |
| Monthly Insights | 3-5 bullet takeaways from the past month. | `monthly` |
| Newsletter Idea | Short newsletter-style post/teaser. | `ideas` |
| Video Script | 45-60s talking-head script: hook, 2-3 beats, CTA. | `videos` |
| Carousel Slide | Single slide of body copy: one idea, minimal words. | `carousel` |
| Infographic | Structured data/step breakdown (headers + bullets). | `carousel` |
| Reel Script | Vertical short-form script (15-30s), scroll-stopping first 2s. | `videos` |
| Podcast Notes | Repurposed episode notes with key quotes and takeaways. | `ideas` |

## Every post must include

Attention hook · body with story/insight · CTA · 3-5 hashtags · 3-6 SEO/GEO keywords · short lines and line breaks for scannability.

See the `hook-generation` skill and [content/hooks/hook-library.md](../../../content/hooks/hook-library.md) for hooks, and the `content-writing` skill and [content/cta/cta-library.md](../../../content/cta/cta-library.md) for CTAs.
