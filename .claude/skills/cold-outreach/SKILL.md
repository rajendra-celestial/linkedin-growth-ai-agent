# Cold Outreach

## Rules

- Lead with the prospect's problem, not the sender's product. Research-backed specificity (their company, role, a visible signal) beats generic personalization tokens.
- One clear ask per message. Multi-ask cold messages get ignored.
- Keep it under 100 words for a first-touch message.
- Always give an easy "no" (e.g. "worth a quick chat, or should I check back later?") — pressure reduces response rates in cold contexts.

## Steps

1. Identify the specific trigger for reaching out now (a job change, funding news, a pain point they posted about).
2. Write the message: trigger → relevant problem → one-line value → soft ask.
3. Pair with a `connection-request-writer` note if this is a first LinkedIn touch, since cold outreach usually starts with a connection request.
